The simplest workflow

Follow these steps during the hands-on part of the tutorial.

Open workspace

Click Open workspace. Sign into GitHub if asked.

Make a copy

If GitHub asks, create your own copy of the repository before editing.

Edit files

Change files in psychophysics/tasks/ or add images under images/.

Preview site

Open the forwarded port called 8000 to see the tutorial site with your edits.

Run task

Open the changed task from the preview site and check that it behaves as expected.

Common edits

These are the files you are most likely to change.

Task HTML

Change an experiment

Edit files in psychophysics/tasks/. These files control the jsPsych task shown to participants.

Object 2AFC task ↗Drawing 2AFC task ↗Ratings task ↗N-back task ↗
Images

Add or replace stimuli

Add image files to the matching folder. Keep filenames simple, with no spaces. Then update the task or metadata so the new image path is used.

Object images ↗Drawing images ↗Rating images ↗N-back images ↗

What to check after editing

Small path errors can break browser experiments, so use this checklist.

Image paths

Make sure image paths match the exact folder and filename, including capitalization such as images/obj_2AFC/im0.png.

Task starts

Open the edited task from the preview website and confirm that the first trial loads without a missing image icon.

CSV downloads

Complete a short run and confirm that the task still downloads a CSV file at the end.

Tip: GitHub Pages shows the official shared version. Your workspace preview shows your edited version. Use the workspace preview when testing changes.
