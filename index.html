GitHub Pages setup

Use this when creating the new public repository.

Recommended setup

  1. Create a new GitHub repository, for example cvr-summer-school-2026.
  2. Upload all files from this folder to the repository root.
  3. Go to Settings → Pages.
  4. Choose GitHub Actions as the source, or deploy from the main branch root.
  5. Open the published Pages URL and test each task and Colab button.

Instructor checklist

  • Confirm the repo branch is named main, or update the branch field in the launcher.
  • Keep the folder names unchanged so relative image paths keep working.
  • Tell students to sign into Google before launching Colab notebooks.
  • Ask students to download their jsPsych CSV at the end of each task.
