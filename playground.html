Edit arrays such as val, ch1, ch2, or correct_choice. Keep related lists the same length.

Timing

Change presentation time

Find values like trial_duration: 100 and try a longer or shorter duration.

Images

Upload a new image named like im999.png, then include 999 in the relevant image list.

Instructions

Edit the welcome or instruction text and test how it changes the participant experience.
